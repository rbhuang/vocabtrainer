# 单词背诵训练器 — 功能规格说明书

版本：1.0  
平台：macOS  
技术栈：Python 3.11 / PyQt6 / edge-tts

---

## 1. 系统概述

单词背诵训练器是一款单机桌面应用，通过"随机出题 → 限时回忆 → 用户判定"的循环帮助用户背诵单词。

---

## 2. 数据规格

### 2.1 词表文件

| 项目 | 说明 |
|------|------|
| 源文件 | `~/Desktop/words.csv` |
| 进度文件 | `~/Desktop/words_tmp.csv` |
| 格式 | CSV，两列：`word,meaning` |
| 编码 | UTF-8（支持 BOM） |
| 去重规则 | 相同单词仅保留首次出现的释义 |

### 2.2 加载优先级

1. 若存在 `words_tmp.csv` → 加载该文件（断点续背）
2. 否则 → 加载 `words.csv`（全量词表）
3. 两者均不存在 → 显示"未找到词表文件"

---

## 3. 核心训练流程

```
启动 → 随机抽词 → 倒计时(N秒) → 显示释义 → 等待用户操作
                                                    │
                                    ┌───────────────┼───────────────┐
                                    ▼               ▼               ▼
                                保留(Y)         记住了(N)       3秒无操作
                                    │               │               │
                                    │          从词表移除         自动保留
                                    └───────────────┴───────────────┘
                                                    │
                                              0.8秒后抽取下一词
                                              （词表为空则显示完成）
```

### 3.1 倒计时阶段

- 显示当前单词（32pt 粗体，居中）
- 释义区域清空
- 按钮禁用（防止误操作）
- 若 TTS 开启，朗读英文单词
- 每秒更新状态栏：`倒计时: N 秒...`

### 3.2 作答阶段

- 显示释义
- 按钮启用
- 若 TTS 开启，朗读中文释义；朗读结束后启动自动保留计时（3 秒）
- 若 TTS 关闭，直接启动自动保留计时（3 秒）

### 3.3 自动保留

- 触发条件：作答阶段 3 秒内无用户操作
- 行为：等同于按下"保留"

---

## 4. 用户操作

### 4.1 按钮与快捷键

| 操作 | 按钮文本 | 快捷键 | 可用时机 | 行为 |
|------|----------|--------|----------|------|
| 保留 | 保留 (Y) | Y | 作答阶段 | 保留当前词，0.8秒后下一词 |
| 移除 | 记住了 (N) | N | 作答阶段 | 从词表移除，0.8秒后下一词 |
| 暂停 | 暂停 (P) | P | 任何时候 | 暂停/恢复所有计时器和TTS |
| 退出 | 退出 (X) | X | 作答阶段 | 保存进度并关闭窗口 |

### 4.2 快捷键规则

- 无需修饰键，直接按字母键
- P 键在任何状态下均可用（含按钮禁用时）
- Y / N / X 仅在按钮启用且未暂停时响应
- 通过全局 `eventFilter` 捕获，无焦点要求

---

## 5. 暂停功能

### 5.1 暂停时

- 停止倒计时定时器
- 停止自动保留定时器
- 停止 TTS 播放
- 禁用保留/移除按钮
- 按钮文本变为"继续 (P)"
- 状态栏显示"⏸ 已暂停"

### 5.2 恢复时

- 还原暂停前的状态栏文本
- 若处于倒计时阶段：恢复倒计时（从剩余值继续）
- 若处于作答阶段：启用按钮，恢复自动保留计时

---

## 6. 进度保存

### 6.1 触发时机

- 关闭窗口（点击窗口 X 按钮）
- 按退出按钮或快捷键 X
- Cmd+Q 退出应用

### 6.2 保存行为

- 将当前 `words_list` 写入 `~/Desktop/words_tmp.csv`
- 仅在词表非空时保存
- 保存前停止所有计时器和 TTS

### 6.3 重置进度

- 删除 `~/Desktop/words_tmp.csv` 即可从头开始

---

## 7. 文字转语音 (TTS)

### 7.1 配置

- 界面复选框控制开关，默认关闭
- 运行时可随时切换
- 关闭时立即终止正在播放的语音

### 7.2 语音选择

| 文本类型 | 判断条件 | 语音 |
|----------|----------|------|
| 中文 | 包含 CJK 字符 (U+4E00–U+9FFF) | zh-CN-XiaoxiaoNeural |
| 英文 | 不含 CJK 字符 | en-US-AriaNeural |

### 7.3 词性缩写展开

朗读前自动将词性缩写转为中文全称：

| 缩写 | 展开 | 缩写 | 展开 |
|------|------|------|------|
| n. | 名词 | v. | 动词 |
| vt. | 及物动词 | vi. | 不及物动词 |
| adj. | 形容词 | adv. | 副词 |
| prep. | 介词 | conj. | 连词 |
| pron. | 代词 | num. | 数词 |
| art. | 冠词 | int. | 感叹词 |

匹配规则：使用 `\b` 词边界 + 转义点号，长缩写优先匹配。

### 7.4 播放机制

- 后台线程生成临时 mp3 文件
- 使用系统 `afplay` 命令播放
- 播放完成后清理临时文件
- 新语音请求会终止正在播放的语音（stop → 重新 speak）

## 8. 界面布局

```
┌──────────────────────────────────────┐
│          [单词] (32pt 粗体)           │
│                                      │
│          [释义] (20pt, 自动换行)       │
│                                      │
│          [状态信息] (14pt)             │
│                                      │
│  [保留(Y)] [记住了(N)] [暂停(P)] [退出(X)] │
│                                      │
│  倒计时(秒): [SpinBox]    ☑ 🔊 TTS   │
│                                      │
│          剩余: M / N (12pt)           │
└──────────────────────────────────────┘
```

- 最小窗口尺寸：500 × 350
- 所有文本居中对齐
- 字体：Arial

---

## 9. 时间常量

| 常量 | 值 | 用途 |
|------|----|------|
| DEFAULT_COUNTDOWN | 3 秒 | 默认倒计时时长 |
| AUTO_KEEP_DELAY_MS | 3000 ms | 自动保留等待时间 |
| TRANSITION_DELAY_MS | 800 ms | 操作后到下一词的过渡延迟 |

倒计时可通过界面 SpinBox 调整（范围 1–30 秒），即时生效于下一词。

---

## 10. 边界情况

| 场景 | 行为 |
|------|------|
| 词表文件不存在 | 显示"未找到词表文件"，按钮不可用 |
| 词表为空 | 同上 |
| 最后一个词被移除 | 显示"🎉 恭喜！你已完成全部 N 个单词！" |
| 所有单词完成后退出 | 词表为空，不写入文件 |
| TTS 服务不可用 | 静默失败，打印错误到控制台，不影响训练流程 |
| edge-tts 未安装 | TTS 复选框禁用，tooltip 提示安装方法 |
| 快速连续按键 | 首次按键触发操作后按钮立即禁用，忽略后续按键 |
