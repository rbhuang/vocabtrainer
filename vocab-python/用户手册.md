# 单词背诵训练器 — 用户手册

## 简介

单词背诵训练器是一款 macOS 桌面应用，帮助你通过随机抽取、限时回忆的方式高效背诵单词。支持文字转语音(TTS)朗读，自动保存学习进度。

---

## 安装

双击 `VocabTrainer.app` 即可运行，无需安装 Python 或任何依赖。

> 首次打开时 macOS 可能提示"无法验证开发者"，请前往「系统设置 → 隐私与安全性」中点击"仍要打开"。

---

## 词表准备

在**桌面**目录下放置 `words.csv` 文件，格式如下：

```csv
abandon,v. 放弃；抛弃
ability,n. 能力；才能
absolute,adj. 绝对的；完全的
```

- 每行两列：**英文单词** 和 **中文释义**（用逗号分隔）
- 编码：UTF-8
- 释义中可包含词性缩写（如 `n.`、`v.`、`adj.`），TTS 朗读时会自动展开为中文

---

## 使用流程

1. **启动后**，程序自动从桌面加载词表，随机显示一个单词
2. **倒计时阶段**（默认 3 秒）：屏幕显示单词，尝试回忆释义
3. **倒计时结束**：显示释义，等待你做出判断
4. **选择操作**：
   - **保留** — 还没记住，下次继续复习
   - **记住了** — 已掌握，从词表中移除
5. **如果 3 秒内无操作**，自动执行"保留"并跳到下一个单词
6. **全部单词移除后**，显示完成提示

---

## 按钮与快捷键

| 按钮 | 快捷键 | 功能 |
|------|--------|------|
| 保留 (Y) | `Y` | 保留当前单词，下次还会出现 |
| 记住了 (N) | `N` | 移除当前单词，不再出现 |
| 暂停 (P) | `P` | 暂停/继续训练 |
| 退出 (X) | `X` | 保存进度并退出 |

> 快捷键无需配合修饰键，直接按字母即可。暂停键 `P` 在任何时候都可用。

---

## 设置

### 倒计时时间

界面底部的「倒计时(秒)」可调整每个单词的思考时间，范围 1–30 秒，即时生效。

## 文字转语音 (TTS)

勾选界面底部的「🔊 文字转语音」后：

- 显示单词时朗读**英文单词**
- 倒计时结束后朗读**中文释义**
- 朗读完成后才开始 3 秒自动保留倒计时

> TTS 功能已内置，无需额外安装。需要网络连接（使用 Microsoft Edge 在线语音服务）。

---

## 进度保存

- **退出时自动保存**：无论通过退出按钮、快捷键 X、还是关闭窗口，都会自动将剩余单词保存到桌面的 `words_tmp.csv`
- **下次启动自动恢复**：程序优先读取 `words_tmp.csv`，从上次中断的地方继续
- **重新开始**：删除桌面上的 `words_tmp.csv`，程序将从 `words.csv` 重新加载完整词表

## 常见问题

**Q: 启动后显示"未找到词表文件"？**  
A: 确认桌面上存在 `words.csv` 或 `words_tmp.csv` 文件。

**Q: TTS 没有声音？**  
A: 确保网络连接正常（TTS 使用 Microsoft Edge 在线语音服务），并已勾选界面中的语音选项。

**Q: 如何重置进度？**  
A: 删除桌面上的 `words_tmp.csv` 文件即可。
